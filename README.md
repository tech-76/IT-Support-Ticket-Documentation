# IT Support Ticket Documentation

This repository contains practical IT support and service desk documentation examples. The goal of this project is to demonstrate troubleshooting ability, ticket documentation, technical communication, escalation awareness, and user-focused support.

## Included Documentation

* Password reset ticket example
* Outlook troubleshooting ticket
* VPN troubleshooting ticket
* Microsoft 365 support documentation
* Active Directory password reset notes
* DNS troubleshooting checklist
* cPanel web hosting support notes
* Incident response documentation lab

## Skills Demonstrated

* Technical troubleshooting
* Service desk ticket documentation
* Microsoft 365 support
* Active Directory fundamentals
* Networking and DNS basics
* Email and web hosting support
* Cybersecurity incident documentation
* Clear written communication
