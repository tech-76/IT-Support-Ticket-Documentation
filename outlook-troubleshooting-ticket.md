# Outlook Troubleshooting Ticket Example

## Ticket Summary

**Issue Type:** Email Support  
**Category:** Microsoft Outlook / Microsoft 365  
**Priority:** Medium  
**Status:** Resolved  
**Affected User:** End User  
**System:** Outlook Desktop App / Outlook Web App  

## Scenario

A user reported that Microsoft Outlook was not receiving new emails. The user stated that Outlook showed as connected, but new messages were not appearing in the inbox.

## User Impact

The user was unable to receive important business emails in the Outlook desktop application.

## Initial Questions Asked

- Are you able to access email through Outlook Web App?
- Are other users experiencing the same issue?
- When did the issue start?
- Are you receiving any error messages?
- Are emails delayed, missing, or only not showing in the desktop app?
- Are you connected to the internet or VPN?

## Troubleshooting Steps

1. Confirmed the user had internet connectivity.
2. Verified that Microsoft 365 services were accessible.
3. Asked the user to sign in to Outlook Web App to confirm mailbox access.
4. Confirmed that new emails appeared in Outlook Web App.
5. Restarted the Outlook desktop application.
6. Checked Outlook connection status.
7. Reviewed whether Outlook was working offline.
8. Checked mailbox storage usage.
9. Recreated the Outlook profile after confirming the issue was limited to the desktop client.
10. Reopened Outlook and allowed the mailbox to resync.

## Root Cause

The Outlook desktop profile appeared to be corrupted or not syncing properly with the Microsoft 365 mailbox.

## Resolution

A new Outlook profile was created and the mailbox was resynced. The user confirmed that new emails were appearing in Outlook.

## User Communication

The user was informed that their mailbox was working correctly through Microsoft 365 and that the issue was isolated to the local Outlook desktop profile. The user was advised to report any future sync delays or repeated Outlook prompts.

## Escalation Notes

No escalation was required. If the issue returned, the next step would be to check Microsoft 365 service health, mailbox rules, add-ins, and device-specific Outlook logs.
