# Password Reset Ticket Example

## Ticket Summary

**Issue Type:** Account Access  
**Category:** Password Reset / Login Support  
**Priority:** Medium  
**Status:** Resolved  
**Affected User:** End User  
**System:** Windows Login / Microsoft 365 / Active Directory  

## Scenario

A user reported that they were unable to sign in to their work account after several failed password attempts. The user stated that they could not access their email, Microsoft 365 apps, or company workstation.

## User Impact

The user was unable to:

- Sign in to Microsoft 365
- Access Outlook email
- Log in to company resources
- Continue normal work tasks

## Initial Questions Asked

- Are you receiving an error message?
- Did you recently change your password?
- Are you able to sign in from another device?
- Are you connected to the company network or VPN?
- Have you tried resetting your password through self-service password reset?

## Troubleshooting Steps

1. Verified the user's identity according to support policy.
2. Confirmed the affected username and email address.
3. Checked whether the account was locked.
4. Reviewed recent failed login attempts.
5. Confirmed that the user was entering the correct username format.
6. Reset the password using the approved administrative process.
7. Required the user to change the temporary password at next login.
8. Confirmed successful login to Microsoft 365 and Outlook.
9. Verified that the user could access required resources.

## Root Cause

The user account was locked due to multiple failed password attempts.

## Resolution

The account was unlocked and a temporary password was issued. The user successfully changed the temporary password and confirmed access to Microsoft 365, Outlook, and workstation login.

## User Communication

The user was advised to:

- Use the correct username format
- Avoid repeated password attempts after a failed login
- Use self-service password reset if available
- Contact IT support if account lockout occurs again

## Escalation Notes

No escalation was required. The issue was resolved at the service desk level.
